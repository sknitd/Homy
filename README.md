# Homy

**Your Mac deserves a better home for everything.**

Homy is a native SwiftUI app for macOS 14+ that puts all your files in one cute, friendly place. It sorts photos, videos, music and documents, finds things from plain-English searches, and helps keep your Mac clean. It needs no account and uses no cloud. Nothing is uploaded, and everything runs on your Mac.

## Features

| Area | What it does |
| --- | --- |
| **Library** | Folder-shaped cards (drawn with a custom `Shape`) for Images, Videos, Music, Documents, Archives and Apps. Each card shows its size, item count and a stack of QuickLook thumbnails. |
| **Clean Up** | Finds duplicates (SHA-256 via CryptoKit), forgotten downloads, old screenshots, unused apps (`kMDItemLastUsedDate`) and large files. Shows "Free up to X GB", and anything you remove goes to the Trash after you confirm. |
| **Duplicates** | Groups byte-identical files and shows them as polaroid-style cards with green **Keep** and red **Trash** badges. When you clean up a group, the copies merge into one card with a **SHA-256 MATCH** badge. |
| **Downloaded From** | Shows where each file came from (WhatsApp, Figma, Slack, Gmail, Safari, Chrome, AirDrop and others), read from `kMDItemWhereFroms` and the `com.apple.quarantine` agent. |
| **Search** | Understands everyday searches such as "pdfs from last week", "large videos", "screenshots from yesterday", "files from WhatsApp" or "songs under 5 mb", and shows what it understood as **Understood as** pills. It can also search inside files with Spotlight (`NSMetadataQuery`). |
| **Copy Text (OCR)** | Select an image or screenshot and press **⌘C Copy Text**. Vision recognizes the text, highlights it with dark blue blocks, copies it, and confirms with a toast. |
| **Sections** | Library, Images, Videos, Music, Documents, Large Files, Downloads, Duplicates, Screenshots, Clean Up and Settings. Each one has its own empty state. |
| **Onboarding** | A welcome screen with the privacy promises, then a folder picker (`NSOpenPanel`). Access is saved as security-scoped bookmarks. |
| **Mascot and icon** | A glossy blue folder holding a smiling cloud. It's drawn as vectors in SwiftUI (`MascotView`), and the app icon PNGs are generated by `scripts/generate_icon.py`. |

## Requirements

- macOS 14 Sonoma or later
- Xcode 16 or later (Swift 5.10+/6 toolchain, macOS 14 SDK or newer)
- Optional: [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)
- Optional: Python 3 + Pillow, only if you want to regenerate the icon (`pip3 install pillow`)

## Build

### Option A: build script (Swift Package Manager)

```bash
./build.sh            # → build/Homy.app (ad-hoc signed, sandboxed)
OPEN=1 ./build.sh     # build and launch
UNIVERSAL=1 ./build.sh  # arm64 + x86_64
```

`build.sh` runs `swift build`, puts together the `.app` bundle (Info.plist, `AppIcon.icns` via `iconutil`, and the compiled asset catalog via `actool` when available), then signs it with `Resources/Homy.entitlements`. Set `SIGN_IDENTITY` to sign with a real certificate.

### Option B: Xcode project (XcodeGen)

```bash
xcodegen generate     # creates Homy.xcodeproj from project.yml
open Homy.xcodeproj   # then Product ▸ Run (⌘R)
```

Before archiving, pick your team under *Signing & Capabilities*. Local runs are ad-hoc signed by default.

### Option C: open the package directly

`open Package.swift` in Xcode, then run the `Homy` scheme. This option skips the app bundle wrapper, so the icon and entitlements aren't applied. Use A or B for the real app.

## First launch

1. Homy shows a welcome screen. Click **Get Started**.
2. Grant access to the folders you want Homy to organize: Pictures, Movies, Music, Documents, Downloads, Desktop, or any other folder. Each click opens a standard macOS folder picker. Homy saves a security-scoped bookmark so it keeps access after relaunch.
3. Homy scans the folders in the background. It also looks at `/Applications` to find unused apps; you can turn that off in Settings.

You can add or remove folders at any time in **Settings ▸ Folders**.

## How it works

- **Scanning** (`FileScanner`): `FileManager` enumerates each granted folder off the main thread. Each file gets a `UTType` category and allocated size. Metadata comes from extended attributes (`kMDItemWhereFroms`, quarantine agent, `kMDItemIsScreenCapture`), with the Spotlight index (`MDItem`) as a fallback.
- **Spotlight** (`SpotlightSearch`): keyword searches also run an `NSMetadataQuery` over the granted folders on `kMDItemFSName` and `kMDItemTextContent`. This finds documents by what's inside them.
- **Duplicates** (`DuplicateFinder`): files are first grouped by size, then each candidate is streamed through `SHA256` in 1 MB chunks. Large files never load fully into memory.
- **Thumbnails** (`ThumbnailProvider`): `QLThumbnailGenerator` with an `NSCache`.
- **OCR** (`TextRecognizer`): `VNRecognizeTextRequest` (accurate, with language correction). Bounding boxes are drawn over the image.
- **Trash**: `FileManager.trashItem` only ever moves files to the Trash, so everything can be restored.

## Privacy

- No account, no analytics, no network calls.
- The app is sandboxed. It can read only the folders you pick, plus Downloads, Pictures, Movies and Music through their standard sandbox entitlements.
- Removing a file moves it to the Trash. Homy never deletes anything permanently.

## Regenerating the icon

```bash
python3 scripts/generate_icon.py
```

The script writes every macOS icon size to `Resources/Assets.xcassets/AppIcon.appiconset`.
